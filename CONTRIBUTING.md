# Contributing

Please follow the [contributor guide](https://qojulia.github.io/SecondQuantizedAlgebra.jl/dev/dev/contributing/)
for development, testing, code style, and pull requests. The guide also lives
in [`docs/src/dev/contributing.md`](docs/src/dev/contributing.md).

Report bugs, request features, and ask support questions through the
[GitHub issue tracker](https://github.com/qojulia/SecondQuantizedAlgebra.jl/issues).
For bugs, include a minimal example, your Julia version, and package versions.
Contributions follow [ColPrac](https://github.com/SciML/ColPrac); maintainers
review proposed changes through GitHub pull requests.
